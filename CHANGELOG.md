# Changelog

## 0.1.0

First Windows x64 release.

- Live adapter monitoring and measured-time coverage.
- Daily/monthly history, date ranges, application details, and CSV export.
- Optional elevated TCP/UDP application event tracing.
- Application-owned Windows Firewall outbound restrictions.
- Tray controls, pause/resume, startup preferences, and themes.
- Local SQLite storage with retention and history reset.
- MIT licensing, contribution guidance, and Windows packaging.
